# Plant_Disease_Detesction_System

A full-stack web application that detects plant diseases from uploaded leaf images using a TensorFlow/Keras deep learning model.

## Features

- Upload plant leaf images
- Predict plant disease category
- Show confidence score and top predictions
- Responsive web interface
- Flask backend API for model inference

## Tech Stack

- Python
- Flask
- TensorFlow/Keras
- Pillow
- Next.js
- React
- TypeScript
- TailwindCSS
